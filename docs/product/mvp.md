# LUVOY — MVP Scope

## MVP Objective

Launch a refined premium experience validating:
- product demand
- UX quality
- premium positioning
- itinerary generation flow
- user retention

---

# MVP Features

## Included

### Authentication
- email login
- signup
- session persistence

### Onboarding
- travel preferences
- travel style
- budget
- travel rhythm
- interests

### Home Experience
- curated destinations
- editorial sections
- premium imagery

### Destination Pages
- curated recommendations
- itinerary suggestions
- destination storytelling

### Itinerary System
- personalized itineraries generated by rule-based engine
- save itineraries
- favorite experiences
- **POI substitution** — edit any activity in the itinerary, choose alternative POIs of same category
- three acts per itinerary: Manhã (free) · Tarde (Premium) · Noite (Premium, dark theme)

### Search
- search destinations by name, country or city
- accessible from Explorar tab (search icon in header)

### Maps Integration
- destination location on detail page
- deep link to Google Maps native for navigation
- POI coordinates stored in database for distance calculations

### PDF Export
- first export free (lifetime, not monthly)
- subsequent exports require Premium (HTTP 402)

### After Dark / LUVOY Noir
- premium section in Explorar tab previewing nocturnal curated content
- paywall at `/premium` with benefits and Stripe checkout placeholder
- `/concierge` and `/checklists` as UI mockups marked "em breve"

### LLM Content Generation (internal — not user-facing)
- OpenAI GPT-4 generates editorial content for each destination (taglines, descriptions, POIs, sections)
- admin endpoint `POST /api/v1/admin/destinations/generate` for on-demand generation
- content saved as DRAFT, reviewed before publishing
- enables unlimited destination expansion without manual writing
