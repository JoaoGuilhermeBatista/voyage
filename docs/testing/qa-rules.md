# QA Rules

# Objetivo

Garantir experiência premium consistente.

---

# O aplicativo NÃO deve:

- parecer poluído;
- travar;
- apresentar animações bruscas;
- usar excesso de cores;
- apresentar loading sem feedback.

---

# UI

Validar:
- spacing consistente;
- tipografia;
- hierarquia visual;
- alinhamentos.

---

# UX

Validar:
- clareza;
- simplicidade;
- fluidez;
- ausência de fricção.

---

# Performance

O app deve:
- abrir rapidamente;
- navegar suavemente;
- evitar telas congeladas.

---

# Premium Feeling

O usuário deve sentir:
- sofisticação;
- confiança;
- clareza;
- leveza.
