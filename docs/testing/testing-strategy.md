# Luvoy — Testing Strategy

## Objetivo

Garantir:
- estabilidade;
- experiência premium;
- consistência visual;
- regras realistas de roteiro;
- funcionamento correto das integrações.

---

# Tipos de Teste

## Frontend
- unit tests
- widget tests
- navigation tests

---

## Backend
- service tests
- API tests
- integration tests

---

## Regras Críticas

O sistema NÃO pode:
- gerar roteiros impossíveis;
- gerar deslocamentos excessivos;
- sugerir locais incompatíveis com perfil;
- quebrar fluxo de onboarding.

---

# Prioridade MVP

## Alta prioridade
- onboarding
- geração de roteiro
- favoritos
- PDF
- Google Maps links

---

# Filosofia

Qualidade de UX é prioridade.

O aplicativo deve parecer:
- fluido;
- premium;
- previsível;
- confiável.
